## In development

Know Your Project is a self-hosted, release-aware knowledge service for MCP clients. It synchronizes Azure DevOps code, work items, repository documents, and HTML mockups, derives semantic facts locally, and stores temporal knowledge behind a restricted read-only interface.

The public MCP boundary intentionally exposes semantic project knowledge rather than raw source files, source snippets, graph queries, credentials, parser output, or internal paths. Release identity and temporal invalidation are application-owned so a query can ask what was true at a specific release rather than only what is true on the live branch.

Graphiti and Neo4j remain private infrastructure, while semantic extraction and embeddings can run through self-hosted model services. This stays in the Lab until the project has a release.
