## In development

Voxveil is exploring real-time vocal reduction with a shared Rust audio core, native platform audio adapters, and a Tauri/React interface. The current implementation includes classic DSP center suppression, optional stem-agnostic AI interfaces, local-only state, and explicit routing rules.

On Windows, the project is working through multiple interception strategies—including an endpoint-scoped audio processing object and controlled virtual-endpoint relay paths—while guarding against stale routes, feedback loops, and unsafe sink selection.

This belongs in the Lab because the engineering surface is substantial and public, but there is no release yet. The portfolio will treat it as active work until a release establishes a completed public milestone.
