## Keep using your mouse while the agent works

Aevra Desktop Use is a native desktop-control MCP server that exposes local desktop backends from Aevra directly to MCP clients over stdio and loopback HTTP. It brings mouse-free background automation to desktop applications: an agent can invoke buttons, set values, select items, and toggle controls through native accessibility APIs (Windows UI Automation, macOS AX, Linux AT-SPI) while you continue using your mouse and keyboard elsewhere.

## App access you can see

Nothing on the desktop is reachable until you explicitly allow it:

- **Application Allowlist**: Manage which executables AI clients may touch through a tray icon and native settings window. Changes apply live to running clients.
- **Semantic Background Operations**: Direct control targeting (`desktop_describe`, `desktop_invoke`, `desktop_set_value`) interacts with controls semantically without synthesizing coordinate clicks.
- **Foreground Fallback**: Explicit screenshot and foreground-input tools handle workflows and graphical applications that require pixels or OS events.
- **Activity History**: Searchable, filterable audit log of desktop actions and HTTP state.
